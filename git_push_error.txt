GIT PUSH ERROR & FIX DOCUMENTATION

----------------------------------

1. ERROR: Authentication Failed

Error Message:
remote: Support for password authentication was removed

Reason:
GitHub no longer allows password-based authentication.

Fix:
- Use Personal Access Token (PAT) instead of password
- Generate token from GitHub → Settings → Developer Settings → Tokens

----------------------------------

2. ERROR: Permission Denied (publickey)

Error Message:
Permission denied (publickey)

Reason:
SSH key not configured properly.

Fix:
- Generate SSH key:
  ssh-keygen -t ed25519 -C "your_email@example.com"

- Add key to GitHub → SSH Keys

----------------------------------

3. ERROR: Failed to Push (Non-fast-forward)

Error Message:
Updates were rejected because the remote contains work

Reason:
Local repo is behind remote repo.

Fix:
git pull origin main --rebase
git push origin main

----------------------------------

4. ERROR: Large File Issue

Error Message:
File exceeds GitHub size limit

Reason:
Large files (>100MB) added

Fix:
- Remove file
- Use .gitignore
- Or use Git LFS

----------------------------------

5. ERROR: Branch Not Found

Error Message:
src refspec main does not match any

Reason:
No commits yet

Fix:
git add .
git commit -m "initial commit"
git push -u origin main

----------------------------------

6. FINAL SUCCESS COMMAND

git add .
git commit -m "final project submission"
git push origin main
