CALL CENTER ANALYTICS SYSTEM – ARCHITECTURE & FLOW

--------------------------------------------------

1. INPUT
-------
- Audio URL (Hindi / Tamil call recording)
- Example:
  https://recordings.exotel.com/exotelrecordings/guvi64/sample.mp3

--------------------------------------------------

2. BACKEND API
--------------
Endpoint:
POST /api/call-analytics

Headers:
x-api-key: guvi123

Query Param:
audio_url: <audio file link>

--------------------------------------------------

3. PROCESS FLOW
---------------

Step 1: Audio Download
- The system downloads audio from the given URL using requests

Step 2: Speech-to-Text
- OpenAI Whisper model converts audio → text
- Supports Hinglish & Tanglish

Step 3: AI Processing (GPT)
- Transcript is sent to GPT model
- Extracts:
  - Summary
  - SOP Compliance
  - Payment Category
  - Rejection Reasons
  - Keywords

--------------------------------------------------

4. FEATURES IMPLEMENTED
----------------------

✔ Voice-to-Text Processing
✔ AI-Based Text Summarization
✔ SOP Validation (Greeting & Closing detection)
✔ Payment Categorization:
    - EMI
    - Full Payment
    - Partial Payment
    - Down Payment
✔ Rejection Analysis
✔ Keyword Extraction

--------------------------------------------------
